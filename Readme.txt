This project is a simple portfolio web application designed to showcase projects and skills, providing the best user experience to the end user It's built using the latest version of Bootstrap, HTML5, CSS3, jQuery and SASS.

Features:

-Responsive Design: Fully responsive and optimized for mobile and desktop.
-Interactive UI: Smooth animations and transitions to enhance user interaction.
-Project Showcase: Display your projects with detailed descriptions, technologies used, and images.
-Smooth Scrolling: Easy navigation through sections like Home, About, Experience, Education, Projects, and Contact.
-Modern Technologies: Built using the latest web technologies like Bootstrap 5, jQuery, and SASS.

Technologies Used:

-HTML5: For structuring the web pages.
-CSS3: For styling the application with modern CSS properties.
-Bootstrap 5: For responsive layouts and components.
-jQuery: For DOM manipulation and enhanced interactivity.
-SASS: For efficient and manageable stylesheets with variables and nesting.


Description:

1. assets/: Contains all the assets (images, icons, etc.) used in the project.

2. css/: Contains the compiled CSS files from SASS.

3. js/: Contains custom JavaScript files.

4. index.html: The homepage of the portfolio.

5. project-details.html: The details page for each project.


Running the Application:
1. In terminal, clone the repository
	git clone https://github.com/your-username/portfolio.git

2. Run the index.html files
